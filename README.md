# 🚀 CareerPilot AI

An AI-powered career guidance platform built using Python and Streamlit.

## 🌟 Features

- 🎯 Career Prediction
- 📊 Career Analytics
- 🧩 Skill Gap Analysis
- 📄 Resume Analyzer
- 💼 Career Guide
- 💰 Salary Prediction
- 🏢 Company Recommendations
- 🤖 AI Career Mentor
- 📈 Reports and History

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Machine Learning
